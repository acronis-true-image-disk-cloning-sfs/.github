## Troubleshooting Common Issues

Install issues? Create recovery media from the installed app rather than a downloaded ISO, then boot from it to confirm.  
Performance problems? Exclude temporary folders and pause cloud sync clients during imaging to reduce I/O contention.  
License/activation? Activate with the account that purchased the subscription and refresh the license from settings.  
Compatibility? Verify that the target disk is at least as large as the used space, or enable proportional resize.  
Update failures? Restart before updating and disconnect external drives that may be locked by antivirus scans.
